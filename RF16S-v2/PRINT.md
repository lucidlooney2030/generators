# Anycubic print notes — RF16S-v2

Nozzle path is a slicer setting, not an STL setting. Use this:

1. Import one STL at a time (or all four if they fit).
2. Supports: Off.
3. Brim/skirt in the app: Off.
4. Wall order: outer walls first (cleaner magnet pockets).
5. Infill: gyroid 20%.
6. Slow the first 3 layers. Do not fan the first layer.
7. Let the bed cool before you peel the printed brim.
